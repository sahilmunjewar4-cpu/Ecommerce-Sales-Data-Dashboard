# 🛒 Ecommerce Sales Data Dashboard

## 📊 Project Overview

The **Ecommerce Sales Data Dashboard** is an interactive Business Intelligence and Data Analytics dashboard developed using **Microsoft Power BI**.

The project is designed to analyze e-commerce sales data and provide meaningful insights into sales performance, profit, products, categories, payment methods, order status, monthly sales trends, and city-wise sales.

The dashboard provides an easy-to-understand visual interface that allows users to interact with the data using filters such as **City** and **Month**.

---

## 🎯 Project Objective

The main objective of this project is to transform raw e-commerce sales data into an interactive and informative Power BI dashboard.

The dashboard helps users:

- Analyze overall sales performance.
- Understand monthly sales trends.
- Compare sales across different cities.
- Identify high-performing products.
- Analyze sales by product category.
- Understand different order statuses.
- Analyze payment methods used by customers.
- Compare product-wise sales.
- Analyze profit generated by different categories.
- Use interactive filters for better data exploration.
- Support data-driven business decision-making.

---

## 🛠️ Technologies and Tools Used

The project was developed using the following technologies:

- **Microsoft Power BI Desktop** – Dashboard development and data visualization
- **Power Query** – Data cleaning and transformation
- **DAX (Data Analysis Expressions)** – Calculated measures and analytical calculations
- **Power BI Data Modeling** – Data relationships and analysis
- **Microsoft Bing Maps** – City-wise geographical visualization
- **GitHub** – Project documentation and version control

## 📈 Dashboard Features

The dashboard contains multiple interactive visualizations that provide different perspectives of the e-commerce data.

### 1. Sales by Order Status

A pie/donut chart represents the distribution of sales according to different order statuses:

- Pending
- Cancelled
- Returned
- Delivered

This visualization helps understand how sales are distributed across different order conditions.

---

### 2. Sales by Month

A line chart displays the variation in sales across different months.

The dashboard currently provides analysis for months including:

- January
- February
- March
- April
- May
- June

This helps identify changes and trends in monthly sales performance.

---

### 3. Sales by City

A geographical map visualization is used to analyze sales based on city/location.

The dashboard includes city-level filtering and analysis for locations such as:

- Bengaluru
- Delhi
- Jaipur
- Lucknow
- Other available locations in the dataset

The map makes it easier to understand the geographical distribution of sales.

---

### 4. Sales by Category

A column chart compares total sales across different product categories.

The visualization helps identify which categories contribute more to overall sales.

Example categories shown in the dashboard include:

- Electronics
- Home
- Fashion
- Furniture

---

### 5. Sales by Product

A bar/column chart displays sales generated by individual products.

Products included in the visualization include:

- Mouse
- Bottle
- Chair
- Watch
- Laptop
- Shoes

This allows users to identify products with higher and lower sales contributions.

---

### 6. Sales by Payment Mode

A donut chart visualizes sales based on different payment methods.

Payment modes represented in the dashboard include:

- Net Banking
- COD
- UPI
- Other available payment modes

This provides insights into customer payment preferences.

---

### 7. Total Sales

A dedicated KPI/card visual is used to display the overall **Total Sales** value.

This provides a quick summary of the sales performance without requiring users to analyze individual charts.

---

### 8. Product-wise Sales Comparison

A horizontal bar chart compares the contribution of individual products to total sales.

The visualization makes it easy to compare products such as Mouse, Bottle, Chair, Watch, Laptop, and Shoes.

---

### 9. Profit by Category

A column chart represents the profit generated by different product categories.

This helps identify categories that contribute significantly to the overall profitability of the business.

---

## 🎛️ Interactive Filters

The dashboard provides interactive filters that allow users to explore the data dynamically.

### City Filter

Users can select a specific city to analyze sales for that location.

Examples:

- Bengaluru
- Delhi
- Jaipur
- Lucknow

### Month Filter

Users can select individual months to analyze monthly performance.

Available months include:

- January
- February
- March
- April
- May
- June

When a filter is selected, the dashboard visuals update according to the selected data.
